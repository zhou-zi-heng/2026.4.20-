# ZenMux 创作者工作站 🐙

专为创作者打造的纯净、高效、安全的 AI 对话与写作辅助工具。

## 🔒 隐私与安全声明 (必读)
1. **API Key 绝对安全**：本工具**不会**在服务器端存储你的任何 API Key。你的 Key 仅保存在你当前使用的**浏览器本地缓存 (LocalStorage)** 中。
2. **数据本地化**：你的所有对话记录、挂载的知识库文件均保存在你的浏览器本地，刷新网页、切后台均不会丢失。
3. **无数据库**：本工具没有后端数据库，开发者无法查看你的任何对话内容。

## 💡 核心功能
- **多引擎无缝切换**：支持自定义 Base URL 和模型映射，随时切换不同的大模型。
- **动态知识库挂载**：支持 TXT, MD, PDF, DOCX。可选择“全局常驻”或“单次消息跟随”。
- **防丢机制**：刷新网页不丢数据；AI 输出中断可一键断点续写。
- **沉浸式导出**：支持导出纯净版 TXT、Word 文档以及精美的 HTML 对话记录。

## 📱 手机端使用建议
直接在手机浏览器打开链接即可使用。建议将网页“添加到主屏幕”以获得类似原生 App 的全屏体验。
